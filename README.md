# 🌌 Cosmic Dreams

O Cosmic Dreams é um site interativo e educativo que oferece uma experiência imersiva para explorar o Sistema Solar. Com simulações visuais, informações científicas e design moderno, você pode aprender sobre planetas, estrelas e outros corpos celestes de forma envolvente e divertida.

---
# 🚀 Funcionalidades
- Exploração do Sistema Solar: Visualização dos planetas com imagens e descrições detalhadas.

- Informações Científicas: Dados sobre tamanho, composição, clima e curiosidades de cada planeta.

- Design Responsivo: Experiência otimizada para diferentes dispositivos.

- Interface Interativa: Navegação simples e visualmente atraente.
